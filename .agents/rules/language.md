# Language Standard: Strict English-Only

1. **Source Code & Scripts:**
   - All source code (C++, Python, Batch scripts, QSS stylesheets, HTML/TPL templates) must use English names and English comments.
   - Never write Persian or non-English text inside code comments or string literals.

2. **Documentation & GitHub Content:**
   - All markdown files (`README.md`, `walkthrough.md`, `CHANGELOG.md`, etc.) must be written in fluent, standard English.
   - All Git commit messages, tag messages, GitHub release notes, and issue comments must be strictly in English.

3. **Packaging & Metadata:**
   - All configuration files (`package.ini`, `version.json`, `.env.example`) must contain English descriptions and metadata.
